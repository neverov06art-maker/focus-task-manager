# Focus Task Manager — AI Frontend Demo

Учебное демо для практики AI-assisted frontend development. Приложение написано на чистых HTML, CSS и JavaScript — без сборщика, npm-пакетов и backend.

## Возможности
- Создание, редактирование и удаление задач
- Переключение статуса выполнения
- Поиск по названию и описанию
- Фильтр по приоритету и статусу
- Сортировка по дате создания, приоритету и названию
- Сохранение данных в localStorage
- Адаптивная вёрстка для мобильных экранов

## Запуск
1. Склонируйте репозиторий или скачайте ZIP.
2. Откройте `demo/index.html` в современном браузере.
3. Начните добавлять и редактировать задачи.

Сервер, API-ключи и установка зависимостей не нужны. Интернет используется только для загрузки веб-шрифта; без него приложение также работает.

## Структура
- `demo/index.html` — разметка
- `demo/style.css` — стили и адаптивность
- `demo/app.js` — логика приложения

## Лицензия
Учебный пример; используйте и модифицируйте для обучения.
